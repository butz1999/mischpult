# Anforderungen

Siehe [project.md](project.md).

## Konventionen

* Es gibt einen gemeinsamen Nummernkreis `REQ-xxx` für alle Disziplinen. IDs werden nie wiederverwendet.
* Jede Anforderung ist eine Überschrift der Form `### REQ-xxx Titel`, gefolgt vom Anforderungstext.
* Die ID ist der Anker: Direkt vor der Überschrift steht `<a id="REQ-xxx"></a>`. Verweise lauten `requirements.md#REQ-xxx` und bleiben bei Titeländerungen gültig.

Beispiel:

```markdown
<a id="REQ-001"></a>
### REQ-001 Titel

Anforderungstext.
```

Kategorien sind Zwischenüberschriften (`##`), nach Bedarf.
